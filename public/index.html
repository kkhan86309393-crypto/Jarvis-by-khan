Activate the built-in holographic avatar, or load a licensed, self-contained VRM or GLB locally.

Optional audio sync asks you to share this browser tab's audio. Audio is analyzed locally and is not recorded or uploaded.

Female model requirements and import steps
  1. Browse Sketchfab downloadable models. Filter to CC0 or CC Attribution (CC BY); verify the exact model page grants your intended use and note any attribution requirement.
  2. Choose an adult, human-realistic female model with dark hair, natural skin, and brown eyes. Before downloading, verify it has a rig and facial controls for mouth/jaw, blink, and eye look; listing the word “rigged” alone does not guarantee these.
  3. Download its glTF package and extract it. In Blender, use File → Import → glTF 2.0, check that textures and facial shape keys/bones are present, then File → Export → glTF 2.0 and choose .glb so geometry and textures are embedded. Do not remove the license/attribution information.
  4. Choose Load local 3D avatar and select the exported self-contained GLB (or a compatible VRM). Files up to 20 MB are parsed in this browser; this app does not download, save, or upload them, so select the file again after a reload. Unsupported models leave the portrait active.
